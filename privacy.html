プライバシーポリシー

施行日：2026年10月4日

対象と運営者

本ポリシーは、個人用デスクトップツール clipper と、その説明ページに適用されます。一般利用者の登録は受け付けていません。お問い合わせは kokoro06152002@gmail.com で受け付けます。

アクセス・保存するデータ

  • 接続を許可したアカウントの OAuth アクセストークン・更新トークン、チャンネル識別情報。
  • 運営者が取り扱う映像・音声、文字起こし、字幕、翻訳、動画タイトル、説明、投稿設定、投稿キューと投稿結果。
  • YouTube API 等で取得する投稿済み動画の識別子と統計情報。YouTube 連携の要求権限は動画アップロードとアカウントの読み取りです。

Google や TikTok のパスワードを clipper に入力・保存する方式ではありません。OAuth の許可は各プラットフォームの画面で行います。

使用目的と外部への送信

データは動画編集、翻訳、投稿先確認、許可された投稿、投稿結果の確認と編集の参考情報に使用します。投稿を実行すると、動画ファイルと必要なメタデータを対象プラットフォームへ送信します。

編集・翻訳・区間選定に AI 機能を使う場合、設定された Claude／Codex の処理先（Anthropic／OpenAI）に、文字起こし・編集指示・参考情報が送信される場合があります。現在の実装では、本人の過去の投稿タイトル・本文・視聴回数を編集の参考情報に含める経路もあります。これらのデータが端末内だけに留まるとは説明しません。データを広告主やデータ販売業者へ販売する用途はありません。

保存場所と期間

認証情報と作業データは運営者が管理する端末のファイルおよびデータベースに保存します。認証情報には所有者のみが読み書きできるファイル権限を設定します。AI 処理先や投稿先が受領したデータには、それぞれのサービスの設定・条件・ポリシーも適用されます。

運用方針として、YouTube API 由来の保存データは30日以内ごとに最新の情報へ更新するか削除し、継続保存する認可済み統計についても30日以内ごとに認可と対象動画の存続を確認します。認証トークンは連携に必要な期間だけ保持します。素材・生成動画は必要性を確認して運営者が管理・削除します。

現在、上記の期限管理・削除を一括で自動実行する機能はありません。本番運用には、期限を守れる手動手順または実装の整備が必要です。

接続の取り消しと削除

YouTube へのアクセスは Google アカウントの接続管理 から取り消せます。削除の希望は上記連絡先に、対象アカウントを特定できる情報とともにお知らせください。パスワードや認証トークンは送らないでください。

運用方針として、削除の依頼を受けたデータは速やかに、7暦日以内に削除します。接続の取り消し時も不要となったトークンと関連する保存データを削除します。端末内のデータ削除や接続取り消しによって、既に YouTube や TikTok に投稿した動画が削除されることはありません。投稿先の動画は対象サービスの管理画面で削除してください。

説明ページについて

この説明ページにはアカウント登録、広告、アクセス解析スクリプト、動画埋め込みを設置しません。公開先のホスティング事業者は、ページ配信やセキュリティのために通常のアクセス情報を処理する場合があります。GitHub Pages で公開する場合は GitHub のプライバシー方針も適用されます。
